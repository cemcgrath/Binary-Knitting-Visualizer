# Binary-Knitting-Visualizer

Turn text into a knitting stitch chart and flat-knitting row instructions. Choose binary or Base64 encoding, adjust the width, and repeat your message. Zeroes are knit stitches and ones are purl stitches as viewed from the front.

[Open the knitting visualizer](https://cemcgrath.github.io/Binary-Knitting-Visualizer/)

The UI runs entirely in your browser. You can also open `index.html` locally.
